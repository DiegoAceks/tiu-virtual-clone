# TIU Virtual – clon de interfaz

Réplica en HTML, CSS y JavaScript puro de la pantalla "TIU Virtual" (reloj en vivo, fecha, foto de perfil y tarjeta con datos del alumno). Proyecto de práctica de maquetación responsive.

> Usa datos de ejemplo. No es un documento de identificación ni reemplaza la app oficial.

## Uso
Abre `index.html` en el navegador (o publícalo con GitHub Pages).

## Personalizar
Edita el objeto `DATOS` al inicio de `script.js`.

## Publicar en GitHub Pages
1. Sube la carpeta a un repositorio.
2. Settings → Pages → Branch `main` → carpeta `/ (root)` → Save.
